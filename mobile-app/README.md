# MealOps mobile app

## Local requirements

- Node.js 22.11 or newer.
- JDK 17 for Android native builds.
- Android SDK 36 with Build Tools 36.0.0, NDK 27.1.12297006, and CMake 3.22.1.

The local Expo config plugin in `plugins/with-java-17.js` selects JDK 17 during
Android prebuilds. It checks `EXPO_JAVA_HOME`, `JAVA_HOME`, Gradle-provisioned
JDKs, and common installation locations on Windows, macOS, and Linux. If JDK 17
is missing, prebuild stops with an actionable error instead of failing later in
Prefab/CMake.

When several JDKs are installed, set `EXPO_JAVA_HOME` to the JDK 17 directory
before running the build.

## Run locally

```sh
npm install
npm run android
```

The `android/` and `ios/` directories are generated by Expo and intentionally
ignored by Git. To regenerate Android after changing native configuration:

```sh
npx expo prebuild --clean --platform android
npm run android
```
